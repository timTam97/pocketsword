# Using SimpleScripture

SimpleScripture brings Bible reading, commentary and word study together on
iPhone and iPad. All five study resources are included in the app:

- King James Version (KJV).
- Matthew Henry's Concise Commentary (MHCC).
- Strong's Greek and Hebrew dictionaries.
- Robinson's Greek morphology resource.

Reading and searching work offline. The included resources are fixed; there
is no catalogue of additional translations or module downloads.

## Read

Use the reference picker to choose a book, chapter and verse. The chapter
arrows move backward and forward. Switch between Bible and Commentary to
read the passage or Matthew Henry's notes.

Reading options include red-letter text, headings, footnotes, Strong's numbers
and morphology where the selected resource supplies them. Enable Strong's
numbers and tap a number to open its dictionary entry. Links inside an entry
let you continue your word study.

Tap a verse number to open its actions, including bookmarking the passage.
Verse-per-line mode separates the verses; prose mode groups Bible verses into
paragraphs.

## Search

Choose the Bible or commentary, then build its search index when prompted.
The index is created on your device from the included text; it is not a download.

Enter words or a phrase. Search options let you match all words, any word or
an exact phrase, and narrow the search to the Old Testament, New Testament or
whole text. Strong's searching is available for the KJV.

Open a result to read it in context. The result's copy action copies the
reference and passage text.

## Library

Return to saved bookmarks and reading history, or browse the dictionaries.
Bookmark folders help organise passages and can carry a highlight colour.

SimpleScripture has its own app identity. It does not automatically import
bookmarks, preferences or history from an existing PocketSword installation.

## Settings and About

Choose a reading font and text size, keep the display awake while reading,
or lock the reading orientation. Open About for the project link, feedback,
upstream credits and complete offline licence notices.

## Help and feedback

[Open an issue on GitHub](https://github.com/timTam97/pocketsword/issues).
Include the app version, device, OS version, the passage or search involved,
and the steps needed to reproduce the problem.

The in-app feedback link prepares a GitHub issue draft with app and OS versions;
you review and submit it yourself. GitHub issues are public, so omit personal
information and private reading notes.
